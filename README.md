# Hotel Booking End-to-End Automation Framework

## Project Overview
This project is a Hybrid Test Automation Framework developed for automating hotel booking workflows using Selenium WebDriver, Java, TestNG, Cucumber BDD, and Maven.

The framework follows the Page Object Model (POM) design pattern for better maintainability, scalability, and reusable test components.

---

## Technologies Used
- Java
- Selenium WebDriver
- TestNG
- Cucumber BDD
- Maven
- Page Object Model (POM)
- Extent Reports
- Git & GitHub

---

## Framework Features
- Hybrid Automation Framework
- Reusable Page Classes
- Cucumber BDD Scenarios
- Explicit Wait Handling
- Dynamic XPath Handling
- Extent Report Generation
- Screenshot Capture on Failure
- Maven Build Management

---

## Test Scenarios Automated
- User Login
- Hotel Search
- Room Selection
- Booking Workflow
- Validation Scenarios
- End-to-End Booking Flow

---

## Project Structure
src/main/java → Page classes and utilities  
src/test/java → Test classes and step definitions  
src/test/resources → Feature files and configuration  
target/ → Reports and execution files
